# MacMonitor - 设计文档

**项目**: MacMini 活动监视器 (iOS App)
**日期**: 2026-03-10
**版本**: 1.0

---

## 1. 项目概述

**项目名称**: MacMonitor
**项目类型**: iOS 原生应用 (SwiftUI)
**核心功能**: 在手机上实时监控 Mac Mini 的系统活动
**目标用户**: Mac Mini 用户，想要随时随地监控设备状态

---

## 2. 技术架构

### 2.1 系统架构

```
┌─────────────┐      WiFi/HTTP       ┌─────────────┐
│   iPhone    │  ◄──────────────►   │  Mac Mini   │
│  (SwiftUI)  │    局域网API         │ (HTTP服务)  │
└─────────────┘                     └─────────────┘
```

### 2.2 通信协议

- **协议**: HTTP REST API
- **端口**: 8080 (默认)
- **刷新频率**: 2秒
- **数据格式**: JSON

### 2.3 API 接口

| 接口 | 方法 | 描述 |
|------|------|------|
| `/api/stats` | GET | 获取全部系统数据 |
| `/api/cpu` | GET | 仅CPU数据 |
| `/api/memory` | GET | 仅内存数据 |
| `/api/disk` | GET | 仅磁盘数据 |
| `/api/network` | GET | 仅网络数据 |
| `/api/processes` | GET | 进程列表 |

## 3. 功能模块

### 3.1 仪表盘 (Dashboard)

- 4个核心指标卡片：CPU、内存、磁盘、网络
- 网络实时曲线图（最近60秒）
- 快速入口：进程列表、应用列表

### 3.2 CPU 监控

- 总体使用率（百分比 + 进度条）
- 每核心负载（条形图）
- CPU 型号和频率信息

### 3.3 内存监控

- 已用/可用内存（环形进度条）
- Swap 使用情况
- 内存分类（App/系统/缓存）

### 3.4 磁盘监控

- 各分区容量（饼图）
- 读写速度（实时数字）
- 磁盘健康状态

### 3.5 网络监控

- 上传/下载速度（实时曲线）
- 当前连接数
- 网络接口列表

### 3.6 进程监控

- Top 15 进程排行
- 按 CPU / 内存排序
- 进程详情（PID、CPU%、内存%）

### 3.7 应用监控

- 当前运行的应用程序
- 活跃应用高亮
- 应用图标和名称

## 6. 数据模型

### 6.1 SystemStats

```swift
struct SystemStats {
    let cpu: CPUStats
    let memory: MemoryStats
    let disks: [DiskStats]
    let network: NetworkStats
    let processes: [ProcessInfo]
    let apps: [AppInfo]
    let timestamp: Date
}
```

### 6.2 CPUStats

```swift
struct CPUStats {
    let usage: Double          // 0-100
    let cores: Int
    let perCoreUsage: [Double] // 每核心使用率
}
```

### 6.3 MemoryStats

```swift
struct MemoryStats {
    let used: UInt64           // bytes
    let total: UInt64
    let swap: UInt64
    let percent: Double
}
```
